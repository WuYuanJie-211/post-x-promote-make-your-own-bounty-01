# post-x-promote-make-your-own-bounty-01

Promote make.fun's make-your-own-bounty post on X.

This entry is a single X post by [@WuYuanJie17](https://x.com/WuYuanJie17) that
quotes/links make.fun's post
(https://x.com/makefunai/status/2124915864336236646), carries a photo, mentions
make.fun / @makefunai, and includes the play code
`makefun-sled-sundial-calendar`. The post points readers to
https://make.fun/sponsor/new, where anyone can create their own bounty.

Scoring is replies + reposts + quotes on the X post.

## Entry

- Post address: see `POST.json` (filled in once the post is live on X)
- Play code: `makefun-sled-sundial-calendar`
- Promoted post: https://x.com/makefunai/status/2124915864336236646
- Sponsor link: https://make.fun/sponsor/new

## Check

```sh
node main.ts
```

`main.ts` reads `POST.json`, validates the post URL, play code, sponsor link
and promoted post URL, and prints a one-line summary. It refuses a
placeholder `POST.json` and exits non-zero, so a placeholder can never be
submitted as a real entry.
